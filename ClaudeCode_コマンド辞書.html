Claude コマンド辞書

基本の使い方 【標準コマンド】対話中に /コマンド を入力(例: /compact) 【短縮指示】/コマンド 対象・目的・条件・希望する出力形式(例: /skeptic この計画が失敗する理由を3つ挙げて) 見つけ方:下の検索欄にコマンド・別名・目的・記入例の一部を入れると絞り込めます(例:要約、リスク、メール)。

「標準コマンド」「CLI」「ショートカット」は Claude Code に実在する機能です。「短縮指示」は画像で共有されていた独自の略称で、Claude の標準搭載コマンドではありません。使う場合は文中に添えるか、スキル/カスタムコマンドとして自分で定義してください。標準コマンドと同名のもの(/review・/plan・/resume・/simplify など)は標準コマンドが優先されます。バージョンにより内容が異なるため、最新は /help で確認してください。
