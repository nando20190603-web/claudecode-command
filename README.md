## 内容の区分

- **標準コマンド・CLI・キーボード操作**: Claude Code に実在する機能です。バージョンにより異なるため、最新は `/help` で確認してください。
- **短縮指示**: SNS 等で共有されていた**独自の略称**です。Claude の標準搭載コマンドではありません。標準コマンドと同名のものは、標準コマンドが優先されます。
